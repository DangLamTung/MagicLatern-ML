Picture Style Editor recipes (generated from the film_sim filter core)
======================================================================

Each block is what Picture Style Editor needs for one stock: a tone curve
and, for the six colour axes, the hue / saturation / brightness change that
the filter applies.  Enter them, save the .pf3, register it with EOS
Utility into User 2, boot with the module, then clone User 2 -> User 1.

tone curve inputs (grey ramp): [0, 32, 64, 96, 128, 159, 191, 223, 255]

LIMITS: PSE has a tone curve plus six hue axes.  The filter also does
shadow/highlight split toning and highlight desaturation, which PSE
cannot express, so a .pf3 built from these numbers is a close
approximation, not a bit-exact copy.  Leave the PSE base style and its
sliders at default - the curve below already contains contrast, black
point and shoulder.  Once the style is in a user slot, cloning it to
User 1 copies it byte for byte, so the camera is then exact.
